## 🎨 CARACTERÍSTICAS VISUALES

### Animaciones Disponibles
```
✨ fadeUp        - Aparición suave desde abajo (al scroll)
✨ slideInLeft   - Entrada desde la izquierda
✨ slideInRight  - Entrada desde la derecha
✨ pulse-scale   - Pulsación en números
✨ float         - Efecto flotante sutil
```

### Efectos Interactivos
```
🖱️ Hover Scale      - Elementos que crecen al pasar
🖱️ Hover Shadow     - Sombra dinámica
🖱️ Hover Color      - Cambio de color
🖱️ Hover Translate  - Elevación de tarjetas
```

### Colores Principales
```
🟢 Verde        #22c55e (Primario)
🔵 Azul         #3b82f6 (Secundario)
🟡 Amarillo     #fbbf24 (Tertiary)
🔴 Rojo         #ef4444 (Alertas)
⬛ Negro        #000000 (Fondo)
⬜ Gris         #64748b (Texto)
```

### Tipografía
```
Font: Inter (Google Fonts)
Pesos: 400 (regular), 600 (semibold), 800 (bold)
Responsive: Escalas automáticas en móvil
```
