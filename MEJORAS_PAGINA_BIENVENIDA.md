## 🎨 Características Técnicas

### Librerías Utilizadas
- **Tailwind CSS**: Framework de estilos
- **Font Awesome 6.4.0**: Iconos profesionales
- **JavaScript Vanilla**: Sin dependencias externas

### Animaciones CSS
```css
- fadeUp: Entrada suave desde abajo
- slideInLeft/Right: Entrada lateral
- pulse-scale: Pulsación repetida
- float: Efecto flotante
```

### JavaScript
- Carrusel automático con control manual
- Observer API para animaciones al scroll
- Event listeners para navegación suave
- Pausable con mouse enter/leave
